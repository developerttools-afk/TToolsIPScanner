2.2 Lokale Datenverarbeitung

Die App speichert folgende Daten ausschließlich lokal auf deinem Gerät:

  • Scan-Ergebnisse: IP-Adressen, Hostnamen, MAC-Adressen, offene Ports (temporär, nur während aktiver Nutzung)
  • Einstellungen: Custom-Ports, Sortier-Optionen, Scan-Modus-Präferenzen
  • OUI-Datenbank: Hersteller-MAC-Zuordnung (lokal gespeichert, optional aktualisierbar)
  • Geräte-Aliase: Selbst vergebene Gerätenamen
  • DNS-Cache: Zwischengespeicherte Hostname-Auflösungen (temporär)

Diese Daten verlassen niemals dein Gerät. Es gibt keine Cloud-Synchronisation und keine Server-Übertragung.

3. Berechtigungen

3.1 Lokales Netzwerk (iOS)

Die App benötigt die Berechtigung "Lokales Netzwerk", um Geräte in deinem LAN zu scannen. Diese Berechtigung wird beim ersten Scan angefordert.

Zweck: Netzwerk-Discovery, Port-Scanning, MAC-Adressen-Erkennung

Datenverarbeitung: Alle Scan-Vorgänge bleiben in deinem lokalen Netzwerk. Es werden keine Daten an externe Server gesendet.

4.1 IEEE OUI-Datenbank (optional)

  • Keine Nutzerdaten: Es werden keine persönlichen Informationen übermittelt
  • Optional: Du kannst die App ohne Update nutzen (lokale Datenbank vorhanden)

4.2 Keine weiteren Dienste

  • ❌ Kein Backend oder eigene Server

5. Datenspeicherung

Alle Daten werden ausschließlich in den Standard-iOS/macOS-Speicherbereichen der App gespeichert:

  • UserDefaults: App-Einstellungen
  • App-Container: OUI-Datenbank, temporäre Scan-Ergebnisse

Privacy Policy

TTools IP Scanner | Version 1.30 | Last updated: August 21, 2026

Summary: The app collects no personal data. All scan results stay on your device. There is no backend, no analytics, no tracking.

1. Data Controller

Thorsten Albers
Email: developerttools@gmail.com

2. Data Collection

2.1 What the App Does NOT Collect

  • ✅ No personal data
  • ✅ No location data
  • ✅ No contacts
  • ✅ No photos or videos
  • ✅ No usage data or analytics
  • ✅ No advertising IDs or tracking
  • ✅ No diagnostic data

2.2 Local Data Processing

The app stores the following data exclusively locally on your device:

  • Scan results: IP addresses, hostnames, MAC addresses, open ports (temporary, only during active use)
  • Settings: Custom ports, sorting options, scan mode preferences
  • OUI database: Manufacturer-MAC mapping (stored locally, optionally updatable)
  • Device aliases: Self-assigned device names
  • DNS cache: Cached hostname resolutions (temporary)

This data never leaves your device. There is no cloud sync and no server transmission.

3. Permissions

3.1 Local Network (iOS)

The app requires "Local Network" permission to scan devices on your LAN. This permission is requested on first scan.

Purpose: Network discovery, port scanning, MAC address detection

Data processing: All scan operations stay within your local network. No data is sent to external servers.

4. External Services

4.1 IEEE OUI Database (optional)

The app offers an optional update function for the OUI database (manufacturer identification by MAC address).

  • Source: IEEE Standards Association (https://standards-oui.ieee.org/oui/oui.txt)
  • Data transmission: HTTP request to IEEE server (publicly available)
  • No user data: No personal information is transmitted
  • Optional: You can use the app without updates (local database included)

4.2 No Other Services

The app uses:

  • ❌ No analytics services (e.g., Google Analytics, Firebase)
  • ❌ No crash reporting tools
  • ❌ No advertising networks
  • ❌ No social media integration
  • ❌ No backend or own servers

5. Data Storage

All data is stored exclusively in the app's standard iOS/macOS storage areas:

  • UserDefaults: App settings
  • App container: OUI database, temporary scan results

Deletion: All data is automatically deleted when you uninstall the app.

6. Your Rights

Since the app does not collect or transmit personal data, no GDPR-relevant processing occurs. You still have full control:

  • Data deletion: Uninstall the app
  • Revoke permissions: iOS/macOS Settings → TTools IP Scanner → Permissions

7. Data Sharing

No data is shared with third parties.

The app has no backend server, no analytics, and no cloud services.

8. Security

Since all data stays local and the app does not make network connections outside your LAN (except optional OUI update), your scan results are maximally protected.

9. Children

The app is rated 4+ (no inappropriate content). No data from children is collected.

10. Changes

This privacy policy may be updated with app updates. Changes will be communicated in the app.
