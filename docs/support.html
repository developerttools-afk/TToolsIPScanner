Häufig gestellte Fragen (FAQ)

1. Wie starte ich einen Scan?

  1. Gib deine Netzwerk-IP ein (z.B. 192.168.1.0) oder wähle aus "Zuletzt gescannt"
  2. Optional: Aktiviere "Vollständiger Port-Scan" für erweiterte Port-Liste
  3. Tippe auf "Scan starten"
  4. Beim ersten Mal: Erlaube "Lokales Netzwerk" (iOS)

2. Warum werden keine Geräte gefunden?

Mögliche Ursachen:

  • ❌ Lokales Netzwerk nicht erlaubt → iOS-Einstellungen → TTools IP Scanner → Lokales Netzwerk
  • ❌ Falsche Netzwerk-IP → Prüfe deine Router-Einstellungen (z.B. 192.168.1.0 oder 10.0.0.0)
  • ❌ Firewall blockiert Scan → Prüfe Netzwerk-Einstellungen
  • ❌ Keine Geräte im Netzwerk aktiv

3. Wie funktioniert die OUI-Datenbank?

Die OUI-Datenbank (Organizationally Unique Identifier) ordnet MAC-Adressen Herstellern zu:

  • Lokal vorhanden: App enthält eine Basis-Datenbank
  • Update: Einstellungen → OUI-Datenbank → "OUI-Liste aktualisieren"
  • Quelle: IEEE Standards Association (öffentlich verfügbar)

4. Was ist der DNS-Cache?

Der DNS-Cache speichert Hostname-Auflösungen zwischen, um wiederholte Scans zu beschleunigen:

  • Anzeigen: Einstellungen → DNS-Cache → Statistiken
  • Löschen: "Cache leeren"
  • Gültigkeit: 5 Minuten pro Eintrag

5. Wie bearbeite ich Gerätenamen?

  • iOS: Gerät antippen → Details → "Hostname-Alias bearbeiten"
  • macOS: Gerätenamen direkt in der Tabelle antippen
  • Aliase überschreiben Scan-Hostnamen und bleiben gespeichert

6. Was ist der Unterschied zwischen Quick & Full Scan?

  • Quick Scan: Nur deine Custom-Ports (Standard: 21, 22, 80, 443)
  • Full Scan: Custom-Ports + erweiterte Standard-Port-Liste
  • Einstellung: Ports-Editor → Eigene Ports definieren

7. Warum werden MAC-Adressen nicht angezeigt?

  • macOS: MAC-Adressen werden über ARP-Tabelle abgerufen (funktioniert meistens)
  • iOS: Keine direkte MAC-Erkennung möglich → Heuristik über Ports/Hostnamen
  • Manche Geräte verbergen ihre MAC-Adresse

8. Ist die App sicher?

Ja, aber:

  • ✅ Alle Daten bleiben auf deinem Gerät
  • ✅ Keine Cloud-Synchronisation
  • ✅ Kein Backend oder externe Server
  • ✅ Keine Analytics oder Tracking
  • ⚠️ Scanne nur Netzwerke, für die du berechtigt bist!

Frequently Asked Questions (FAQ)

1. How do I start a scan?

  1. Enter your network IP (e.g., 192.168.1.0) or select from "Recently scanned"
  2. Optional: Enable "Full Port Scan" for extended port list
  3. Tap "Start Scan"
  4. First time: Allow "Local Network" (iOS)

2. Why are no devices found?

Possible causes:

  • ❌ Local Network not allowed → iOS Settings → TTools IP Scanner → Local Network
  • ❌ Wrong network IP → Check your router settings (e.g., 192.168.1.0 or 10.0.0.0)
  • ❌ Firewall blocking scan → Check network settings
  • ❌ No active devices on network

3. How does the OUI database work?

The OUI database (Organizationally Unique Identifier) maps MAC addresses to manufacturers:

  • Locally included: App contains a base database
  • Update: Settings → OUI Database → "Update OUI List"
  • Source: IEEE Standards Association (publicly available)

4. What is the DNS cache?

The DNS cache stores hostname resolutions to speed up repeated scans:

  • View: Settings → DNS Cache → Statistics
  • Clear: "Clear Cache"
  • Validity: 5 minutes per entry

5. How do I edit device names?

  • iOS: Tap device → Details → "Edit Hostname Alias"
  • macOS: Tap device name directly in table
  • Aliases override scan hostnames and are saved

6. What's the difference between Quick & Full Scan?

  • Quick Scan: Only your custom ports (default: 21, 22, 80, 443)
  • Full Scan: Custom ports + extended standard port list
  • Settings: Port Editor → Define custom ports

7. Why are MAC addresses not shown?

  • macOS: MAC addresses retrieved via ARP table (usually works)
  • iOS: No direct MAC detection possible → Heuristics via ports/hostnames
  • Some devices hide their MAC address

8. Is the app safe?

Yes, but:

  • ✅ All data stays on your device
  • ✅ No cloud sync
  • ✅ No backend or external servers
  • ✅ No analytics or tracking
  • ⚠️ Only scan networks you're authorized to access!
